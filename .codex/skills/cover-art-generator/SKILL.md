# Cover Art Generator

## Activation

Use when creating or modifying cover-generator templates, editing controls, exports, canvas rendering, artwork presets, or producer artwork workflows.

## Workflow

1. Use Beatstor tokens, existing typography, and real track metadata as inputs.
2. Keep templates constrained: De Roche Archive, Dark Listening Room, Contact Sheet, Audio Document, Poster Deconstruction, Image Mask.
3. Preserve editable source configuration until the user confirms export.
4. Adapt layouts per output format instead of stretching one square design.
5. Avoid copying competitor templates, logos, artwork, or proprietary layouts.

## Checklist

- Beginner mode stays simple: template, image, main text, colour variation, waveform variation, export.
- Advanced mode exposes grid, type scale, blend mode, waveform style, metadata, texture, crop marks, and token overrides.
- Safe areas are visible and respected.
- Export presets cover square, streaming, social, YouTube, beat-store card, banner, playlist, and download artwork.
- Generated output remains original and Beatstor-branded.

## Expected Output

Template/control/export changes with source-state, brand-consistency, mobile, and copyright-safety notes.
