# Competitor Feature Audit

## Activation

Use only when a concrete competitor URL, video, app, or screenshot is supplied or available to inspect.

## Workflow

1. Inspect the direct source and record what is actually visible.
2. Document interaction flow and feature behavior without guessing.
3. Compare each feature to existing Beatstor coverage.
4. Define an original Beatstor adaptation and technical requirement.
5. Respect IP boundaries: no exact branding, graphics, copy, layouts, logos, artwork, source code, or trademarked identifiers.

## Checklist

- Direct source inspected.
- User problem and value identified.
- Existing Beatstor equivalent checked.
- Original design difference defined.
- Priority and implementation status documented.
- No unverified claims.

## Expected Output

`docs/prod-by-jack-feature-audit.md` or a matching audit document with feature, problem, value, coverage, adaptation, technical requirement, priority, and status.
