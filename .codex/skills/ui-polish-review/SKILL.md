# UI Polish Review

## Activation

Use after feature work, before release, or when a page feels unfinished, noisy, generic, inconsistent, or visually accidental.

## Workflow

1. Inspect the affected page in context with its surrounding layout and persistent player.
2. Compare cards, rows, forms, modals, drawers, and buttons against existing patterns.
3. Check loading, empty, error, hover, active, disabled, and mobile states.
4. Remove decorative noise and accidental inconsistencies.
5. Verify reduced motion and responsive behavior for visual changes.

## Checklist

- Alignment, spacing, typography, and hierarchy feel intentional.
- Controls do not overlap the player or navigation.
- State styling is consistent.
- Forms and modals feel finished.
- Animation communicates state and does not delay interaction.
- Page does not read as a generic AI dashboard.

## Expected Output

Polish fixes, pages reviewed, states checked, screenshots or browser notes when available, and remaining visual concerns.
